# Loop ledger: phone version of the HORUS control app (2026-11-01)

STATUS: OPEN

Source: the phone app design decided with the user on 2026-11-01, recorded in
`HORUS — Design Document v2.md` ("Phone app design") and `PLAN.md` phase 6, on top of the finished
control app (`LOOP_CONTROL_APP.md`, `STATUS: DONE`). This file is the loop's memory and its stop
switch: the gate `~/projects/seref_omp_tools/seref_loop/bin/seref-loop-gate LOOP_PHONE_APP.md` (run
by `/seref_manager run LOOP_PHONE_APP.md` or `/loop --until`) stops the loop only when the line above
reads `STATUS: DONE`, no `- [ ]` is left, every `- [x]` carries `DONE:`/`INVALID:` evidence and every
`- [!]` a `BLOCKED:` reason.

The phone app in one paragraph: the same page the AI pilot service already serves
(`horus/commander/web/`), opened on the user's phone through `tailscale serve` on the laptop's
tailnet HTTPS address and installable to the home screen. It logs in with its own phone token, shows
no camera, shows the AI's work as a feed where each AI turn's commands and results are folded into a
collapsed "Show commands" block, has a compact state line, large HOLD / LAND / HOME (with the
operator lock) and a mission box, and a map whose static layers are stored on the phone so only
small live data travels.

Before the loop: HTTPS certificates must be enabled for the tailnet (Tailscale admin console → DNS →
HTTPS Certificates). On 2026-11-01 `tailscale status --json` showed `CertDomains: null`. The
laptop is `<laptop>.<tailnet>.ts.net` (100.64.0.1), Tailscale 1.104.1, operator user set
(no sudo needed); the user's phone on the tailnet is `phone` (Android, 100.64.0.2).
