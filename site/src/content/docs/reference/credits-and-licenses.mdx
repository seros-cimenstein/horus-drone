## Gazebo simulation model attributions

When running the optional Gazebo Harmonic simulation (`sim/`), HORUS adapts several 3D models from **Gazebo Fuel**.

### Human models

- **`person_standing` and variants (`person_red`, `person_blue`, `person_green`):** Adapts OpenRobotics' [Standing person](https://fuel.gazebosim.org/1.0/OpenRobotics/models/Standing%20person) from Gazebo Fuel (**CC0 1.0**). All four share a single `standing.dae` mesh (in `person_blue/meshes`, pointing textures to `person_standing`), while each variant's `model.sdf` overrides the shirt material using a unique texture filename so Gazebo's Ogre2 renderer does not cache and reuse the first loaded color.
- **`person_laying`:** Adapts OpenRobotics' [ElderMalePatient](https://fuel.gazebosim.org/1.0/OpenRobotics/models/ElderMalePatient), authored by **Roselle Carmen** and licensed under [**CC BY 4.0**](https://creativecommons.org/licenses/by/4.0/). The upstream Fuel description also credits Autodesk Character Generator and Mixamo. The local copy localizes the SDF model name and mesh URI and marks the model static.

## Core open-source ecosystem

HORUS builds directly on the work of the following projects:

- **[ArduPilot](https://ardupilot.org/)** (GPL-3.0) — Flight control firmware and Copter 4.7.1 SITL (`--model JSON`).
- **[MuJoCo](https://mujoco.org/)** (Apache-2.0) — Cross-platform rigid-body physics and offscreen rendering for the built-in 3D **Test world**.
- **[Gazebo Harmonic](https://gazebosim.org/)** (Apache-2.0) — Optional advanced 3D simulation environment.
- **[Model Context Protocol (MCP)](https://modelcontextprotocol.io/)** (MIT) — Streamable HTTP tool transport connecting the **AI pilot** and external clients to the **Drone board**.
- **[ONNX Runtime](https://onnxruntime.ai/)** (MIT) & **[OpenCV](https://opencv.org/)** (Apache-2.0) — CPU inference, image processing, and CSRT visual tracking.
- **[Tailscale](https://tailscale.com/)** — WireGuard-based private tailnet HTTPS proxy (`tailscale serve`) for the Phone Companion App.
- **[Astro Starlight](https://starlight.astro.build/)** (MIT) — Documentation framework powering this site.
