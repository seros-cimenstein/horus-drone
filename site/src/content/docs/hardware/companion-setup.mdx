---
title: Companion Setup
description: Run the Drone board (horus mcp) on a real flight controller and companion computer.
---

On physical hardware, the **Drone board** (`horus mcp`) runs on the drone's onboard companion computer, or directly on your laptop over USB or telemetry radio via **HORUS Studio**.

## Option A: Direct USB / Telemetry Radio in HORUS Studio

1. Open **HORUS Studio → Settings → Hardware & External Sim → Direct USB / Radio**.
2. Pick your detected serial port (e.g. `/dev/ttyACM0`, `COM4`) and baud rate (`115200` for USB, `57600` for telemetry radio), or enter `udpin:0.0.0.0:14550`.
3. Optionally enter a camera index (`0`) or RTSP URL; leave blank to run flight-only without perception (`--no-perception`).
4. Click **Connect Session**.

## Option B: Remote Companion Computer (`horus mcp`)

Install the lean `board` package on the companion computer (e.g. BeagleY-AI / AM67A or Raspberry Pi, with no MuJoCo or cloud LLM SDKs):

```sh
pip install "horus-drone[board] @ git+https://github.com/seros-cimenstein/horus-drone.git"
HORUS_CONFIG=/path/to/horus.yaml HORUS_MCP_TOKEN="replace-with-a-long-random-secret" horus mcp
```

If you cloned the repository onto the companion computer, install from the local checkout with `pip install -e ".[board]"`.

### Flight-only mode (`--no-perception`)

If you want to fly or bench-test **Flight moves** without a camera stream, start with `horus mcp --no-perception` (or set `perception.enabled: false` in YAML). NumPy, OpenCV, and ONNX Runtime are only imported when perception starts, so a flight-only server needs just the `server` (or `board`) extra and a live MAVLink flight link.

:::caution[Keep the Drone board private]
The **Drone board** serves plain HTTP bound to `127.0.0.1:8000` by default. Never expose port `8000` directly to a public network. Always use a strong `HORUS_MCP_TOKEN`, forward the loopback port over an **SSH tunnel** or **Tailscale**, and connect via **Remote Companion** in HORUS Studio. Keep a hardware RC transmitter ready for immediate `PILOT` takeover.
:::
